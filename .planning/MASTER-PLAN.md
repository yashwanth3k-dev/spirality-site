## Technical SEO rules (locked)

- Use `app/robots.ts` and `app/sitemap.ts` (not `.tsx`)
- No special AI/LLM files or “AI SEO” gimmicks
- Fundamentals: crawlability, indexable text, internal linking, original content, page experience, accurate structured data
- No keyword-spam microsites / scaled thin pages
- No fake FAQ rich-result schema; FAQs for users/answerability only
- Schema only where it matches visible content (Organization, WebSite, BreadcrumbList, Article, careful Service/SoftwareApplication)

## Content rules

- Solution pages use fixed IA: Hero → Problem → What Spirality does → How it works → What gets built → Where it fits → Differentiation → Outcomes → FAQs → CTA
- Industries: 3–5 real verticals only; no thin industry farm
- Insights: original methodology/examples — not trend-spam blogs
- Homepage is category + proof path, not an encyclopedia

## Visual direction

- Spirality: technical, intelligent, confident, human — editorial/minimal, not SaaS-dashboard template
- Bizdaptive: separate brand system (blue `#0000FF`, Neue Haas / Helvetica Neue, strict grid)
